# SnippyScales

A modular **Python–Rust** quantitative trading research and execution platform.

## Design Principles

- Clear separation of research (Python) and execution (Rust)
- Event-driven Rust backtesting engine
- Volatility as a first-class input to all sizing decisions
- Incremental evolution in strategy sophistication
- Avoid unnecessary complexity early; build for scale from the outset
